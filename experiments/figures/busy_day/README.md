# busy_day figures (showcase deck)

Generated by `python experiments/plot_cluster.py` from the busy_day batch (4 controllers x 2 runs,
900 s load test each, app CPU limit 200m, 19 Nov 2026).

| File | What |
|---|---|
| `busy_day_timeline.png` / `.svg` | One representative run per controller: ready pods (request rate as the filled area, right axis) and p95 latency with the 300 ms SLA. 3328x1160 px. |
| `busy_day_tradeoff.png` / `.svg` | Cost (pod-minutes) vs mean p95 latency after warm-up; dot = mean of 2 runs, lines span the runs. 2384x1160 px. |
| `busy_day_timeline_data.csv` | The exact rows in the timeline: one row per controller x 15 s reading, with a `warmup` column. |
| `busy_day_tradeoff_data.csv` | One row per run: pod-minutes, mean/max p95 after warm-up, SLA violations with and without warm-up, and more. |
| `runs/busy_day/<controller>/repeat_<N>/metrics.csv` | The raw telemetry of all 8 runs (columns: `docs/telemetry.md`). |

Warm-up = the first 60 s (readings with `elapsed_s <= 60`): every run starts at 1 pod, and every SLA violation
happened there. There are 0 violations after warm-up in all 8 runs.

## Making your own figures

Use the CSVs above with any tool. To regenerate these figures (or restyle them: colours, sizes and fonts are
constants at the top of the script):

    python experiments/plot_cluster.py --results-dir experiments/figures/busy_day/runs

That writes to `experiments/figures/busy_day/runs/figures/`.
